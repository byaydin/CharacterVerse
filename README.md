# ✦ CharacterVerse

**Explore the Rick and Morty universe.**

CharacterVerse is a web application that lets you explore the fascinating universe of Rick and Morty. Discover characters, travel across different locations, and explore episodes through an interactive and easy-to-navigate interface.

🌐 **Live Demo:** https://byaydin.github.io/CharacterVerse/

---

## 📸 About the Project

CharacterVerse uses data from the [Rick and Morty API](https://rickandmortyapi.com/) to provide information about characters, locations, and episodes from the animated series.

The project focuses on creating a clean and responsive interface while practicing JavaScript, DOM manipulation, API integration, and modular frontend development.

## ✨ Features

- **Explorer:** Browse and discover content from the Rick and Morty universe.
- **Characters:** Explore characters and view detailed information about each one.
- **Locations:** Discover different locations, their dimensions, types, and residents.
- **Episodes:** Browse episodes and explore their details, including featured characters.
- **Dynamic Content:** Fetch and display data directly from the Rick and Morty API.
- **Reusable Components:** Generate character cards and other UI elements using reusable JavaScript functions.
- **Responsive Design:** Navigate the application across different screen sizes.

## 🛠️ Built With

- **HTML5** – Application structure and semantic markup.
- **CSS3** – Styling, layouts, and responsive design.
- **JavaScript (ES6+)** – Application logic, API requests, and dynamic rendering.
- **Rick and Morty API** – Source of character, location, and episode data.
- **Git & GitHub** – Version control and project hosting.
- **GitHub Pages** – Static website deployment.

## 🌐 API Reference

This project uses the [Rick and Morty API](https://rickandmortyapi.com/documentation).

The API provides three main resources:

| Resource   | Endpoint         |
| ---------- | ---------------- |
| Characters | `/api/character` |
| Locations  | `/api/location`  |
| Episodes   | `/api/episode`   |

All data is retrieved dynamically through JavaScript Fetch API requests.

This project was created to practice and improve frontend development skills, particularly:

- Working with REST APIs and asynchronous JavaScript.
- Understanding JavaScript modules and code organization.
- Manipulating the DOM dynamically.
- Building reusable UI components.
- Handling API responses and errors.
- Managing navigation and URL parameters.
- Deploying static websites using GitHub Pages.

### A Note on Development

I intentionally avoided relying heavily on AI when building this project. As a result, some parts of the code may have room for improvement, and there are probably better or more efficient ways to approach certain implementations.

I could use AI to refactor everything and chase a more polished result, but I'd rather have code that I wrote, understand, and learned from than pursue perfection through AI.

For me, this project is more about learning, experimenting, making mistakes, and improving my own development skills than producing perfect code.
